🌦️ Open Meteo AI Weather Prediction API

AI-powered weather forecasting for Sydney, Australia

📋 Project Overview

Description

Open Meteo is modernizing weather forecasting by embedding AI into their services. This project develops machine learning models to predict rain patterns in Sydney, helping clients reduce uncertainty and improve decision-making for operations, events, and resource planning.

The system delivers accurate and timely weather predictions that enable stakeholders including businesses, event organizers, transport providers, and agricultural operations to plan with greater confidence and minimize weather-related risks.

Key Objectives

  • • Deliver accurate and timely weather predictions for Sydney
  • • Help clients reduce uncertainty in daily and long-term planning
  • • Enable proactive risk management for weather events
  • • Improve decision-making for businesses and individuals
  • • Minimize risks related to rainfall through ML predictions

🔌 API Endpoints

GET /health/

Server Health

Returns a welcome message and current server status and the last models version.

Output Format:
{
 "status": "ok",
 "message": "The service is running.",
 "models": {
  "rain_or_not": {
   "version": "v7.rc2",
  },
  "precipitation_fall": {
   "version": "v3.rc2",
  }
 }
}
GET /predict/rain/

7-Day Rain Prediction

Binary classification model that predicts if it will rain exactly 7 days from the input date in Sydney.

Input Parameters:

date: YYYY-MM-DD format
// Date from which to predict rain in 7 days

Output Format:
{
  "input_date": "2023-01-01",
  "prediction": {
    "date": "2023-01-08",
    "will_rain": true
  }
}
GET /predict/precipitation/fall/

3-Day Precipitation Forecast

Regression model that predicts cumulated precipitation volume in mm over the next 3 days in Sydney.

Input Parameters:

date: YYYY-MM-DD format
// Date from which to predict precipitation

Output Format:
{
  "input_date": "2023-01-01",
  "prediction": {
    "start_date": "2023-01-02",
    "end_date": "2023-01-04",
    "precipitation_fall": "28.2"
  }
}
