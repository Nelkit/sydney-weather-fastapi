AMLA-AT2 Meteo API

This API provides weather predictions for Sydney using machine learning models trained on historical Open-Meteo data.

Available Endpoints:

  • / - Project description and endpoints
  • /health/ - API health check
  • /predict/rain/?date=YYYY-MM-DD - Predict if it will rain in exactly 7 days
  • /predict/precipitation/fall?date=YYYY-MM-DD - Predict cumulative precipitation over the next 3 days
